# P0-1b 合併 PR #2 邏輯進 PocketCore、只做 ETF、紅漲綠跌 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans (user chose inline execution). Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 以 PR #2（已合併進本分支）的 App 邏輯為準，把所有不依賴畫面的邏輯移進 `PocketCore`，App 改用套件、刪除重複；拿掉個股；改為紅漲綠跌；並讓 Mac CI 能驗證。

**Architecture:** 「App 現行版本為準」：PR #2 的型別欄位、驗證、訊息原樣搬入套件（加 `public`），只在三處採用 PocketCore 既有較嚴格的規則（見 Global Constraints）。App 的型別名稱保留（例如 `OpenData`、`OfficialDividends` record），P0-1 的 `OfficialQuotes`／`OfficialDividends` enum 併入其中，減少畫面程式改動。

**Tech Stack:** Swift 6.1 toolchain、Swift language mode 5、XCTest、XcodeGen、GitHub Actions `macos-26`。

**Spec:** `docs/superpowers/specs/2026-11-11-etf-pocket-redesign-design.md`；前一份計畫 `docs/superpowers/plans/2026-11-11-p0-1-pocketcore.md`；PR #2 對照表見 ledger（`.superpowers/sdd/2026-11-11-p0-1b-merge-pr2/progress.md` 第一段）。

## Global Constraints

- Linux 測試：`export PATH=/opt/swift-dl/swift-6.1.2-RELEASE-ubuntu24.04/usr/bin:$PATH && swift test --package-path PocketCore`
- App 最低 iOS 18.0；`project.yml` 加 `packages: PocketCore`；`PocketCore` 只連結到 App target（不重複連到測試 target，修 P0-1 review minor #3）。
- PocketCore 不得 import SwiftUI／UIKit／Combine／Security／CryptoKit／Vision／UserNotifications；`CFStringEncoding`、`CFGetTypeID` 這類 Apple 專屬 API 包在 `#if canImport(Darwin)`。
- 搬移時欄位名稱、Codable 鍵、使用者可見文字一字不改；備份 `schema` 仍為 1。
- 採 PocketCore 規則的三處：(1) `StableID` 用純 Swift SHA-256；(2) 外幣級別為代碼結尾 `K` 或 `C`（PR #2 的 OpenData 只認 `K`，與它自己的 LiveProtocol 不一致）；(3) 官方收盤價合併：較新交易日取代，或同日且既有報價在 14:30 前抓取時取代。
- 只做 ETF：官方收盤價、名單、匯入只收 `00` 開頭代碼；指數（加權、櫃買）保留。
- 漲跌顏色：上漲紅、下跌綠（spec D4）。
- 每個 task 結束 `swift test --package-path PocketCore` 全過才 commit；App 端改動以 Task 8 的 Mac CI 驗證。
