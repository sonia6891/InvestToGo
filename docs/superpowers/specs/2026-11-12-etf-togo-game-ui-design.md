- 日期：2026-11-12
- 狀態：**畫面已經使用者看過並同意（「可以，寫規格」）**，本文件待使用者審閱。第 12 節是我的提案，使用者確認前不是定案。
- 設計稿：[ETF 袋著走 UI 方向（設計畫布）](https://claude.ai/artifact/EYVw8j2Ge95kvCHAKdpqbX)。本文件提到的每個畫面都在畫布上，以畫板名稱標示。
- 3D 素材來源：`design/3d/build_blocks.py`（Blender 5.2，無介面執行）。
- 與既有文件的關係：本文件只管「介面長什麼樣、怎麼操作」。帳號、訂閱、資料來源、後端、階段拆分仍以 [2026-11-11 全面改版設計](2026-11-11-etf-pocket-redesign-design.md) 為準。本文件**取代**該文件的 D12（底部五個分頁）與 5.2 節中「皮膚只換材質與配色」「物件用程式產生」兩點。

## 1. 目標

讓使用者打開 App 的感覺像在玩一款精緻的小遊戲，而不是在看一般理財 App：

1. 沒有底部導覽列。首頁是一個「大廳」，功能是大廳裡的 3D 物件。
2. 視覺參考使用者提供的兩張「不無聊」系列 App Store 截圖：純色底、平面光片、白色圓盤加粗色環、啞光 3D 方塊物件、等寬小字、六角框標籤與按鈕、一排打勾圓圈。所有物件與畫面都是我們自己做的，不複製該系列的任何素材。
3. 查資料與記帳也要好玩：ETF 是可收集的圖鑑卡、持續定投就升級、完成任務有獎勵。
4. 換膚是換一整個世界，不只換顏色。

成功標準：

1. 使用者第一次打開，不看說明就知道點大廳裡的物件可以進入功能。
2. 任何畫面兩步內可以到任何主要功能（大廳一步，或六角快選一步）。
3. 三套皮膚在每一個畫面都成立，切換後沒有任何一處還留著前一套的樣子。
4. 符合台灣習慣：紅漲綠跌；所有數字都有文字說明，不只靠顏色。

## 3. 視覺語言（以黑金為基準）

### 3.1 顏色

| 名稱 | 黑金 | 用途 |
|---|---|---|
| `page` | `#1A1A1D` | 底色，整頁純色 |
| `ink` | `#F4F1E8` | 主要文字、白色圓盤、實心按鈕 |
| `sub` | `#A9A397` | 次要文字、等寬標籤 |
| `dim` | `#6E6A63` | 提示文字 |
| `card` | `#232328` | 卡片、任務欄 |
| `line` | `#2C2C32` | 分隔線 |
| `accent` | `#F2B632` | 金：色環、經驗、選中、快選鈕 |
| `up` / `down` | `#F25C54` / `#3BB273` | 漲 / 跌（台灣習慣） |
| 光片點綴 | `#F2777A`、`#3D7BF2`、`#000000` | 只用在平面光片，不用在文字 |

像素、縫線、手繪三套的同名顏色見第 7 節。程式裡一律用名稱取色，不寫死色碼。

### 3.2 字體

| 角色 | 黑金 | 說明 |
|---|---|---|
| 大數字 | Anton | 只用在數字與代號（12、0050、NT$ 286,450） |
| 標題 | Noto Sans TC 900 | 頁面標題、按鈕 |
| 內文 | Noto Sans TC 500/700 | |
| 等寬標籤 | JetBrains Mono | 例：`PKT×012`、`ETF×0050`、價格與漲跌 |

字體檔隨 App 打包，不從網路載入。支援動態字級：大數字最多放大到 1.3 倍，超過就換行或縮小，不切字。

### 3.3 形狀

- **六角框**：標籤（細框）、按鈕（實心或框線）、分類籤。這是黑金最主要的識別。
- **白色圓盤加金色粗環**：主角物件的舞台（開機、會員、升級）。
- **平面光片與月牙**：只當背景裝飾，平面、無陰影，不能蓋到文字或可點的東西。
- **打勾圓圈**：已完成是白色實心圓加黑勾，未完成是灰色細框。
- 手機外框圓角、卡片圓角 22pt；可點區域至少 44×44pt。

### 3.4 3D 物件

- 由圓角方塊、圓弧、圓柱組成，倒角柔順；啞光黑（粗糙度 0.9）與啞光漆金（粗糙度 0.62、低金屬）。
- 光從左上方來，柔和；沒有反射地板、沒有聚光燈。
- 每頁最多一個「主角」物件（大尺寸），其他物件是入口或圖示（小尺寸）。

### 3.5 動態、音效、震動

- 進入功能：物件放大填滿畫面再淡出成功能頁（約 350ms）。返回大廳反向。
- 記錄這個月：金幣從上方掉進口袋，數字跳一下，金色碎片爆開。
- 升級、解鎖成就：全螢幕光片＋圓盤畫面（見 5.11）。
- 每次確認都有短音效與震動；音效可在設定關閉。
- 開啟「減少動態效果」時，所有移動改成淡入淡出，碎片不出現。

## 4. 導航

### 4.1 結構

```
開機 → （第一次）新手引導 4 頁 → 登入 → 大廳
大廳 ─ 點物件 → 找 ETF ─ ETF 詳情 ─ ETF 圖鑑卡
     ├ 點物件 → 配息
     ├ 點物件 → 口袋
     ├ 點物件 → 工具箱 ─ 各工具、會員、換膚
     ├ 點右上靶心 → 成就
     └ 點中央數字 → 定投紀錄（全部月份）
任何功能頁底部：「‹ 大廳」＋金色六角快選＋目前頁名
```

### 4.2 大廳（畫板：大廳）

- 中央：3D 方塊數字＝連續定投月數，下面寫「12 個月」與六角標籤「連續定期定額」。**示範數字一律用 12**（一整年）：13 在國外不吉利，畫布、截圖、商店圖都不出現 13；真實使用時顯示使用者自己的月數。
- 四角各一個 3D 物件入口，下面有六角標籤：左上放大鏡「找 ETF」、右上金幣堆「配息」、左下口袋「口袋」、右下計算機「工具」。
- 頂部狀態列：等級（例 LV.7）、經驗條、金幣數、成就靶心。
- 下方：「本月任務」卡（見 6.3）。
- 底部提示：「→ 點物件進入 ←」。

### 4.3 六角快選（畫板：六角快選）

- 每個功能頁底部中央一顆金色六角鈕；左邊「‹ 大廳」，右邊用金字寫目前頁名。
- 點六角：畫面變暗，五個圓盤沿弧線彈出（找 ETF、配息、口袋、工具、成就），點任一個直接切換；再點六角（變成 ✕）收起。
- 從螢幕左緣往右滑＝回上一層；在第一層功能頁往下滑＝回大廳。

## 5. 畫面

所有範例數字都是示意，畫面上以「示意資料」標註；上線後只顯示使用者自己的資料與官方資料。

### 5.1 開機
光片＋白色圓盤＋金環，圓盤內是 3D「$」。下方：`SKN×001`、「ETF 袋著走」、六角標籤（目前皮膚名）、「存 ETF，也存下好習慣。」、「→ 輕點開始 ←」。

### 5.2 新手引導（畫板：新手引導）
上方四段進度條，可返回。
1. 想養成哪個習慣：定期定額／領息／存錢目標（白色圓盤加金環的 3D 圖示，選中的卡片反白）。
2. 每月投入金額（1,000／3,000／5,000／10,000 六角籤）與想買的 ETF（0050、006208、00878、搜尋其他）。
3. 提醒：扣款日（3–9 日，選中放大）、提醒時間、前一天也提醒。
4. 登入：Apple（實心六角）、Google（框線六角）、Email 連結、條款。

### 5.3 大廳
見 4.2。**新手狀態**（尚未定投）：中央是單獨的 3D「1」（加黑色底座），寫「第 1 個月」＋「今天開始」，任務是「設定第一筆定投」「收集第 1 張圖鑑卡」。連續中斷時：數字歸 1，並顯示「最長紀錄 13 個月」，不嘲諷、不倒扣。

### 5.4 找 ETF
右上 3D 放大鏡；標題「找 ETF」；六角搜尋框；分類籤（全部、市值型、高股息、債券、主題）；清單每列：代號（大數字字體）、名稱、價格、今日漲跌（▲▼ 加百分比，紅漲綠跌）。

### 5.5 ETF 詳情
超大代號（0050）、名稱、類型六角標籤、價格與漲跌；分頁籤：走勢、持股、配息、資訊；金色走勢線（1 月／3 月／1 年／5 年／全部）；四格數據：內扣費用、近一年殖利率、配息頻率、成分股數；主按鈕「加入口袋」，下方連結「用 0050 試算定期定額」。第一次打開一檔 ETF 時收進圖鑑（見 6.4）。

### 5.6 ETF 圖鑑卡
米白卡片加金邊：編號與類型、星等、超大代號、3D 圖示；五條方塊能力條（費用、規模、殖利率、波動、歷史）與數值；黑底「特技」一句白話說明這檔適合誰。下方：同系列收集進度、「PK 比一比」「加入口袋」。左右滑看下一張。能力條是把官方數據換算成 1–10 格，換算規則見 12 節 G5。

### 5.7 口袋
3D 口袋、`我的口袋 · 4 檔`、總市值（大數字）、總損益六角標籤；配置條（每檔一色）；持股列：色點、代號、名稱與占比、市值、報酬率；「＋ 加一檔」。

### 5.8 配息
3D 金幣堆、今年已領（大數字）、標籤（次數與去年比較）；12 個月打勾圈（已領、未領、本月加底線）；即將除息清單（除息日、每股、預估入帳）；「記一筆配息」。

### 5.9 工具箱
兩欄卡片，每張一個 3D 圖示：定期定額試算、費用比較、券商匯入、除息提醒、存錢目標、會員・換膚（主色卡片）。

### 5.10 會員
光片＋圓盤＋3D 皇冠；「口袋會員」、「解鎖全部功能」；三個方案卡（免費、口袋會員、會員＋AI），選中的反白並打勾；主按鈕、恢復購買、條款、隨時可取消。價格與方案內容照 2026-11-11 文件第 7 節；畫面上顯示的價格一律從 App Store 取得，不寫死在畫面。

### 5.11 成就
右上 3D 靶心、「成就」、已解鎖數；三欄徽章牆：已解鎖＝圓盤加色環，裡面是 3D 物件，下面寫達成日期；未解鎖＝暗色問號，下面有進度條與數字。

### 5.12 升級
光片＋圓盤＋3D 金幣堆、`LEVEL×UP`、大字「LV.8」、原因標籤（例：連續定投 12 個月）；獎勵（金幣、新成就或解鎖進度）；「收下」與「分享這一刻」。

### 5.13 換膚
左右滑動的卡片輪播，四套依序：像素、黑金、縫線、手繪。每張卡放那套皮膚自己的口袋（黑金錢袋、像素寶箱、縫線帆布袋、手繪牛仔褲口袋）配上它的底色；不放數字（13 在國外不吉利，卡片也不該像某個人的成績）；正中間一張放大、加白框，左右各露出鄰居一張。卡片下方：頁點＋「2 / 4」；名稱、狀態標籤（使用中／已解鎖／解鎖條件）、一句說明；四個風格圖示可直接點選跳到那套：每套用自己畫風的小圖示代表（像素＝方塊星星、黑金＝金色六角、縫線＝縫線鈕扣、手繪＝鉛筆），底色是那套的底色；圖示由 `design/3d/skins/badges/badges.mjs` 產生 SVG。按鈕依狀態：停在使用中的那套 →「← 滑動試穿 →」；停在已解鎖的 →「換上這套」，按下整個 App 換過去；停在未解鎖的 → 顯示條件（例：LV.10、會員），按鈕改成去升級或看會員。長按卡片＝全螢幕試穿，放開還原。

## 6. 遊戲系統

原則（沿用 2026-11-11 文件第 8 節）：**獎勵好習慣，不獎勵買更多或頻繁交易。** 經驗、金幣、成就都不和投入金額或交易次數掛鉤。

### 6.1 等級與經驗

| 行為 | 經驗 |
|---|---|
| 本月有記錄定投（每月一次） | +100 |
| 完成本月任務（每項） | +40 |
| 第一次收進一張圖鑑卡 | +30 |
| 記一筆配息 | +20 |
| 對帳（持有與券商一致） | +20 |

每級所需經驗與等級上限見 12 節 G1。

### 6.2 金幣
只能靠遊戲行為取得，不能用錢買。用途見 12 節 G2。

### 6.3 本月任務
每月 3 項，從固定題庫依使用者的習慣挑選（例：定投一次、看一次配息、研究 1 檔新 ETF、設定除息提醒、完成一次對帳）。新手任務見 5.3。

### 6.4 ETF 圖鑑
打開一檔 ETF 的詳情就收進圖鑑，不用買。依類型分系列（市值型、高股息、債券、主題…），收齊一個系列解鎖成就。

### 6.5 成就清單
沿用 2026-11-11 文件第 8 節：連續領息、持有週年紀念、定期定額打卡、一年不亂動、對帳達人、省費達人、體檢完成、ETF 圖鑑、除息季限定皮膚、口袋年報、累計領息里程碑。

**設計稿需要修正的一處：** 成就畫面的「存到 50 萬」會鼓勵投入更多，違反原則，改成「累計領息里程碑」。

### 7.2 程式結構
每套皮膚是一份資料（顏色名稱表、字體、形狀元件、音效檔、震動節奏、3D 素材資料夾）。畫面只向「目前皮膚」要東西，不判斷是哪一套。新增一套皮膚＝新增一份資料＋一組 3D 素材，不改畫面程式。

### 7.3 解鎖
依 2026-11-11 文件第 7 節：免費 1 套（黑金），會員全部。像素是否也能靠升級解鎖，見 12 節 G3；手繪怎麼解鎖，見 G6。

### 7.4 之後
主物件專屬造型（像素寶箱）、除息季限定皮膚，列為之後的工作，不在第一版。

### 8.2 製作與匯出

- 全部由 `design/3d/build_blocks.py` 產生，同一份程式切換皮膚（`-- skinall`，環境變數 `ETF_SKIN`）。
- 第一版：靜態圖示匯出透明 PNG（@2x、@3x）。會動或可拖曳轉動的主角（大廳數字、口袋、金幣）另外匯出 3D 模型：iPhone 用 USDZ（RealityKit），安卓用 GLB。
- 像素皮膚的方塊化要先套用再匯出。
- 縫線皮膚同手繪，不用 3D：紙片與縫線由 `design/3d/skins/stitch/stitch.mjs` 產生 SVG。物件對應：12 → 縫在布片上的數字、找 ETF → 摺疊地圖＋大頭針、配息 → 存錢罐、口袋 → 縫上口袋的帆布袋、定期定額試算 → 捲尺、費用比較 → 兩張價格吊牌、除息提醒 → 大頭針釘住的便條、存錢目標／成就 → 紙獎章、會員 → 六角徽章、第一次領息 → 繡了 $ 的硬幣布章。
- 手繪皮膚不用 3D 素材，物件也整個換掉：12 → 正字記號（卌卌||）、找 ETF → 望遠鏡、配息 → 長出硬幣葉子的盆栽、口袋 → 牛仔褲後口袋、定期定額試算 → 月曆、費用比較 → 天秤、除息提醒 → 鬧鐘、存錢目標／成就 → 山頂小旗、會員 → 票券、第一次領息 → 信封滑出硬幣。由 rough.js 產生 SVG（程式在 `design/3d/skins/sketch_doodle/draw.mjs`），App 裡直接用向量圖。
- 匯出後在手機上比對畫布：啞光感、光的方向、顏色要一致。

## 9. 狀態與邊界

| 狀況 | 呈現 |
|---|---|
| 新使用者 | 見 5.3 新手大廳；口袋、配息頁顯示 3D 物件＋一句說明＋一個按鈕，不顯示 0 元大數字 |
| 載入中 | 3D 物件輕微浮動＋等寬字「讀取中」，不用轉圈 |
| 讀取失敗 | 白話說明＋「再試一次」；仍顯示上次成功的資料與時間 |
| 離線 | 頂部細條「離線中 · 顯示 11/12 09:00 的資料」 |
| 虧損 | 口袋總損益照實以綠色顯示，不加任何懲罰動畫或負面文案 |
| 定投中斷 | 數字歸 1，保留最長紀錄，見 5.3 |
| VoiceOver | 3D 主角讀出它代表的值（例：「連續定投 12 個月」）；裝飾光片不朗讀 |
| 減少動態效果 | 見 3.5 |

## 10. 平台

- iPhone：SwiftUI，3D 主角用 RealityKit `RealityView`（最低 iOS 18，沿用既有決定）。
- 安卓：Jetpack Compose，3D 主角用 GLB 模型。畫面結構、皮膚資料、文字共用同一份定義。
- 兩個平台的皮膚資料（顏色、字體、形狀參數）放在同一個 JSON，避免兩邊不一致。

## 11. 驗收

1. 每個畫面截圖與設計畫布並排比對；三套皮膚各比一次。
2. UI 測試：從大廳進出每個功能；六角快選切換每個功能；新手引導完整走一次；換膚後每個畫面都沒有前一套的顏色或字體。
3. 輔助使用：最大字級、VoiceOver、減少動態效果三種設定各走一次主要流程。
4. 效能：大廳 3D 動畫在 iPhone 12 等級的機器維持 60fps。
