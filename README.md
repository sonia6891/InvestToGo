# 投資袋著走 · 原生 iPhone App

> **0.3.0 已於 2026-10-18 上傳 TestFlight 並交給內部測試**（來源 `71a8782`，[編譯與測試](https://github.com/sonia6891/InvestToGo/actions/runs/39159534805)、[簽署上傳](https://github.com/sonia6891/InvestToGo/actions/runs/39161906093)均成功）；尚未確認已在使用者 iPhone 安裝。之後的提交須重跑測試。GitHub 原始碼提交不代表測試或發佈完成。

本工程是唯一持續開發來源，藍白 SwiftUI 五分頁：首頁、探索、持有、配息、工具。當前原始碼版本 0.3.0；發佈狀態與實際測試證據以 RELEASE_STATUS.md 為準，不以這份 README 代表已上傳。

## 新版介面（ui/pocket-redesign 分支）

依「ETF 袋著走」設計稿改版，畫面對應既有資料與功能，沒有資料來源的欄位不顯示估計值。

設計稿在 Figma「ETF 袋著走 設計稿」：https://www.figma.com/design/ivdDhUgFxIzInvJzFZ7KgM （「畫面」六個畫面、「插圖」、「參考範本」三頁，顏色用變數管理）。分類、工具與配息插圖由 Figma AI 產生，以 `python -I WebPreview/prepare_art.py <原圖資料夾> WebPreview/assets` 去白底並裁成 384px 透明 PNG，網頁版與 App 使用同一批圖。

2026-10-16 依五張範本（首頁、探索、持有、配息、工具各六個畫面）再改版，App 與網頁版一致：

- 共用：懸浮半透明導覽列（彩色圓形圖示，內容會透出來；圓鈕是玻璃球，選取時圓形玻璃透鏡像水滴一樣從原本的圓鈕流到新的圓鈕、圖示彈跳、觸覺回饋，往下捲縮成目前分頁的小圓鈕，往上捲或點它展開；iOS 26 用 Liquid Glass，網頁版以 CSS 模擬）、跟隨系統／淺色／深色外觀、所有內頁共用 `AppRoute` 導覽。
- 首頁與內頁：資產總覽卡（總成本、未實現損益、累計配息）、本月已領與下月預估配息、資產走勢、近期配息提醒（含持有 ETF 的官方除息公告）；資產總覽（歷史走勢、資產結構、產業／國家／幣別分布）、本月股息、通知中心、設定、資料來源狀態、隱私與安全、關於。
- 探索與分類：系統用途分類卡、依 ETF 類型快速篩選、完整分類（市場、管理方式、投資策略、產業、配息頻率、資產類別、商品結構）、我的自選（可勾選三檔比較）、ETF 詳情（價格走勢、分類標籤、風險標示、持股組成、基金資訊、官方配息紀錄）、分類依據。
- 持有與管理：我的總市值、持有／交易／配置三分頁、持有明細、新增與編輯持有（總成本含手續費、購入日期、券商選填）、交易紀錄（新增買進／賣出會調整持有並計算已實現損益）、資產配置（ETF 分類、產業分佈、持股透視、前二大占比提醒、券商帳戶）。
- 配息與紀錄：配息月曆（本月已入帳／已公告／預估）、近期配息（官方公告一鍵加入）、配息明細（每股配息、股數、除息日、扣繳費用、實際入帳）、新增配息紀錄（資料來源決定狀態，可帶入官方公告）、確認入帳、年度配息統計（每月長條圖、CSV 匯出）。
- 工具：工具中心（試算／分析／管理）、股息複利、領息目標、定期定額、三檔比較（一年報酬、內扣費用、波動度、近一年殖利率、配息頻率）、持股透視（持股集中度、重疊成分）、備份與券商資料。
- 官方配息資料：`App/Resources/official-dividends.json`（由 `WebPreview/build_data.py` 產生），App 可在「資料來源」直接向證交所與櫃買中心更新。

漲跌依設計稿：上漲綠、下跌紅（`Palette.up`／`Palette.down`），與網頁版一致。分類、工具與配息插圖在 `App/Assets.xcassets/Art`。

## 網頁測試版（WebPreview/）

在 Mac 編譯前，用來在手機上試用新版介面的單頁網頁：`WebPreview/index.html` 加上由 `python -I WebPreview/build_data.py` 從 App 內建名單與年度費用產生的 `etf-data.json`。沒有示範資料，只記錄使用者自己的資料，新開啟時是空的；畫面上不標示資料來源。它是介面試用，不取代 iPhone App；券商 CSV 匯入、成分股與通知只在 App。

- **網頁版 App（可連富果）**：https://sonia6891.github.io/etftogo-web/ ，公開 repo `sonia6891/etftogo-web` 只放建置後檔案。以 `python -I WebPreview/build_pages.py <輸出資料夾>` 產生（加上 App 圖示、主畫面名稱與 manifest），再推到該 repo 的 main。富果金鑰只存在使用者瀏覽器，只傳給 api.fugle.tw。
- **Claude 連結版**：在 Claude 的安全沙盒中執行，無法連線外部網址，所以不能使用富果；資料存在使用者的 Claude 帳號，可跨裝置同步。
- **官方配息資料**：`build_data.py` 打包證交所「ETF 收益分配」（上市 ETF 約兩年的除息日、發放日、每單位金額）與櫃買中心除權息預告（上櫃 ETF 近期公告），用來推算配息頻率、在「近期配息」列出持有 ETF 的公告，並在新增配息紀錄時帶入金額與日期。證交所允許跨站讀取，網頁版可在「設定 › 資料更新」即時更新；櫃買只有打包時的快照。
- 2026-10-16 依五張範本（首頁、探索、持有、配息、工具各六個畫面）改版：懸浮半透明導覽列、深淺色模式、資產總覽、本月股息、通知中心、設定與資料來源、我的自選、完整分類、分類依據、持有明細、交易紀錄（買進／賣出會同步調整持有）、配息明細與確認入帳、年度統計與 CSV 匯出、券商庫存 CSV 匯入、成分股與持股透視（富果 `ownership/etf-holdings`）。範本中追蹤指數、基金規模、保管銀行、Face ID 與券商自動同步沒有可靠來源或網頁做不到，畫面上明確標示。

## 這次補回的功能

- 官方現行上市／上櫃 ETF 名單及更新快取，排除未到掛牌日與歷史商品。2026-10-15 快照為上市 241、上櫃 118，共 359 個證券代碼，包含不同幣別級別；不是 359 個不重複基金。
- 舊 PWA `ETF_CLASSIFIER` v3、舊原生 `ETF_TOGO_NATIVE` v1、planning v2 及目前 schema 1 備份合併匯入。預覽後確認，保留匯入前副本；總成本轉每股成本、實領配息優先、穩定識別碼防止重複。舊手填參考價保存在備份，另行取得行情。
- 所有券商可使用通用 CSV 欄位對應，提供股／張、總成本／單價、帳戶暱稱、驗證預覽與單一帳戶替換。UTF-8、帶 BOM 的 UTF-16 與 Big5。CSV 可同時含個股與 ETF，外幣成本需換成台幣；代號不在內建股票或 ETF 名單、數量或成本無法辨識、欄位比標題多（例如未加引號的千分位逗號）的列，以及合計、備註列，會在預覽列出原因並略過，其餘照常匯入；行尾多出的空欄與較短的列自動對齊。替換帳戶時，略過列上的代號保留上次匯入的庫存。C/K 級別以實際股數匯入。不能匯出 CSV 的券商（例如國泰證券）可「從截圖匯入」：以 iOS 內建文字辨識在手機上讀出代號（或只有名稱時比對股票與 ETF 名單的名稱）、股數與付出成本；可一次選多張分段截圖，不同張之間完全相同的列（代號、股數、成本、現股／融資）視為重疊只算一次，同一張裡的每一批都保留。先在可編輯清單逐批確認，辨識不到的欄位或對不到的代號留空由使用者填選；匯入時同一檔同類別的多批合併成一筆（股數、總成本相加），融資另存一筆並在券商名稱標「（融資）」，融券不匯入。成本依標題分辨每股價格（成本價、均價…）或總金額（付出成本、持有成本…）；標題看不出時以現價判斷，仍判斷不了就留空待確認。預覽列出每股成本、總成本與現價估算的市值、損益；平均成本與現價相差超過 0.3～3 倍時，截圖與 CSV 匯入都會提示。
- 成分股更新／JSON 匯入、持股穿透及兩檔共同權重下限。揭露比例與資料日期都顯示；缺資料不視為零重疊。
- 富果還原日收盤歷史、區間與年化報酬、最大回撤及波動率，最早 2010 年，依 API 年度限制分段查詢。這是供應商還原價格績效，不代表已核實配息再投入總報酬或個人交易損益。
- 292 檔的 2025 年公會申報實際費用比率，包括經理費、保管費、交易手續費、交易稅、申贖扣抵、保證費與其他費用。依官方基金統編或唯一完全相符的正規化子基金名稱配對；沒有模糊名稱推測。資料配對與原始回應雜湊見 Evidence/ReferenceData/snapshot-receipt.json。
- 舊版配息再投入試算及設定持續儲存；保留原有單純複利試算。

## 已確認與尚待實測

使用者已在 iPhone 安裝 0.2.0 (2.3) 並確認取得 0050 真實報價。金鑰只在使用者手機的 iOS Keychain，未提供給建置環境。新版另增加報價幣別確認；成分股與歷史行情仍需使用者以自身資料方案驗證，成分股需要相應富果權限。

使用者已同意本次先測試持有匯入，券商帳戶自動授權同步留待開通各券商正式 API／帳務查詢權限後處理。CSV 匯入不等於自動同步。

年度費用尚未涵蓋全部商品；完整現行契約級距也未全部收錄。缺值明示，另提供有來源、日期的手動記錄。年度快照隨 App 發佈更新；名單可在 App 更新。配息仍由使用者記錄，沒有自動公告同步。

## 建置與儲存

Xcode 26.6 / iOS 17 以上。執行 `xcodegen generate` 產生 ETFToGo.xcodeproj；原生 App，不含 WebView。測試預覽 Bundle ID `tw.sonia.etftogo.uireview`；正式封存覆蓋為 `com.sonia.etftogo`，延續既有 TestFlight App。

GitHub native-ui workflow 執行編譯、單元及操作測試，保留結果與截圖。正式簽署沿用既有私人簽署環境的獨立 ETF 分支，秘密不寫入本工程。App Store Connect App ID 6822974128。

資料保存在 Application Support/ETFToGo/portfolio.json，以原子寫入及 iOS 檔案保護儲存；可重新取得的歷史走勢另存於同資料夾的 portfolio.json.histories，不計入紀錄檔 5 MB 上限，也不寫入備份（舊版存在紀錄檔裡的走勢，下次儲存時移出）；損壞檔案保留並阻止空資料覆寫。行情金鑰使用 Keychain，僅傳送富果官方網域，拒絕轉址，不包含在備份。匯入前副本位於相同資料夾的 Recovery。

App 沒有示範資料：一律顯示使用者自己的持有，新安裝時是空的。`--ui-testing` 使用獨立測試資料檔，CI 截圖也以空資料拍攝。外幣或幣別未確認的報價不混入台幣市值。

圖示沿用既有口袋圖，512 圖放大為 1024 App Icon，沒有宣稱新增圖像細節。分類是整理策略，非收益保證。
